# Product

## Platform

web

## Product Purpose

Show the price history and key financial information for WiseTech Global (WTC.AX) in a single stock overview.

## Capabilities and Constraints

The page uses the existing Python yfinance dependency for Yahoo Finance market data. Quotes are identified by currency and trading date. Missing figures are shown as unavailable.

## Evidence on Hand

The repository contains a React and Vite scaffold and a Python script that queries WTC.AX through yfinance.
