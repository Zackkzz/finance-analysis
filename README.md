# Finance analysis tool

A self-written app for financial analysis. Frontend designed by AI.

## Feature

- gather market information, financial information and news content using [yfinance](https://github.com/ranaroussi/yfinance).
- local AI model to analyse news and generate summary.
- search by company name or symbol and select a security to load its prices, market figures, and news.
- indicators based on real-time data.

## Stack

- frontend: vite, react.js
- backend: python, fastapi, ollama
- ollama for local model hosting
- yfinance for scraping.
- pandas for data processing.
- pandas-ta for analysing indicators.

## Run locally

Create database

```sh
cd src/backend/db
sqlite3 finance_analysis.db < init.sql
```

Start the FastAPI stock API from the repository root.

```sh
uv sync
uv run backend
```

To serve live stock data and news together, run the route app.

```sh
uv run uvicorn backend.route.api:app --reload
```

In a second terminal, start the frontend.

```sh
cd app
npm ci
npm run dev
```

Or run frontend and backend at once.

```sh
cd scripts
./startup.sh
```

Open the local URL printed by Vite. The Python API listens on port 8000, and Vite proxies `/api` to it. The API caches successful responses for five minutes. An internet connection is required for Yahoo Finance data.

Open the [interactive API documentation](http://127.0.0.1:8000/docs) while the backend is running.

## Project layout

- `src/backend/stock_api.py` defines the FastAPI application and server entry point.
- `src/backend/stocks/models.py` defines stock response types.
- `src/backend/stocks/service.py` retrieves and caches Yahoo Finance stock data.
- `src/backend/stocks/news.py` retrieves and validates Yahoo Finance news.
- `src/backend/main.py` provides the raw Yahoo Finance exploration script.
- `app/src/features/stocks/` contains the stock overview, data hook, chart, types, and formatters.
- `docs/impeccable/` contains the product and design documentation.

The frontend commands and source layout are documented in [app/README.md](app/README.md).
